## Must-fix
1. **Reason allowlist: fixed.**
   - `setupReasonVisible` now accepts only 2, 15, 202 and 204.
   - A refusal streak (`SetupRefusal`) replaces "failing since" and resets on any non-refusing
     reason.
   - Tests: 8/200/201/205 never enter; the streak counts from the first refusal and resets on 201.
   - `net_task.cpp` uses the streak.
2. **ASCII: fixed.**
   - `setupAsciiFold()` is host-tested (curly `'`, accents, `"`, emoji → `?`).
   - A non-ASCII SSID shows as `your WiFi` (`setupIsPlainAscii`).
   - The Name is folded before the length check.
3. **Boot overflow: fixed.** `r3-boot-error-notfound` shows `12 s` at the row's right and
   `Not found - 2.4 GHz only?` alone on the next line. `r3-boot-error-portal` is the same.

  only then.
- **Hold:**
  - The fill starts on touch-down, and < 150 ms dropouts are tolerated.
  - `Keep holding` after an early release (`r3-portal-cancel-nudge`).
  - `closes in` is hidden once joined (`r3-portal-joined-nopage`).
- **Gate wording:**
  - `Everything works here.` / `Works here: weather, plane cards, radar. Off here: streets on the
    plane map (it is drawn for a spot 0.4 mi away).` / `Works here: weather and plane cards. Off
    here: the street map and the radar (built for Gilbert, AZ).`
  - A cleared Name gets the placeholder `Name this place`.
- **Time-zone hint:** Arizona's box is checked first (Yuma → Arizona). There is no hint outside
  the US (London → none).
- **Parser disagreement:** closed by design. The page posts decimal numbers, and the firmware
  only range-checks them.
- **Scan again:** `/scan` JSON rebuilds the list only; a typed password survived a rescan in the
  test.
- **Settings Done:** 36 px (`r3-settings-menu`), with the rows moved up.
