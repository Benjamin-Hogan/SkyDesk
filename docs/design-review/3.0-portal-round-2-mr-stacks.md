## Must-fix

1. **"Visible" is a denylist, but the spec says allowlist.**
   - `setupReasonVisible` returns true for *any* reason except 0 and 201. So BEACON_TIMEOUT (200, a router losing power mid-run), CONNECTION_FAIL (205) and ASSOC_LEAVE (8) all count as "visible and refusing". ASSOC_LEAVE is what our own `WiFi.disconnect()` produces.
   - That breaks the rule "never strand itself in setup when the router is off", and the boot hint would then be blank while the portal still opens.
   - *Fix:* make it an allowlist (2, 15, 202, 204, plus 203 ASSOC_FAIL if you want MAC filtering), the same set as "Wrong password?". Host-test that 8, 200 and 205 never enter. Also host-test that `failingMs` resets when the reason flips to 201.

2. **The iPhone's smart punctuation reaches the device font.**
   - Name (optional) typed as `Ben's desk` arrives as `Ben’s desk` (U+2019). An SSID like `Café` is drawn in `Can't join "…"`. Both break the "never non-ASCII" rule, and `setupValidate` counts bytes, so a 20-character name with an accent is rejected with a confusing message.
   - *Fix:* add a pure `setupAsciiFold()`. It maps ‘’“” to `'` and `"`, drops accents where there's an obvious base letter, and turns anything else into `?`. Apply it to `place` on save. For drawing an SSID, fall back to `your WiFi` whenever it isn't pure ASCII. Host-test both.

3. **`boot-error-notfound` overflows its panel.**
   - `Not found - 2.4 GHz only?  Retrying` ends about 6 px past the panel edge, and the countdown is gone (the other state shows `Retrying in 12 s`).
   - *Fix:* the hint line carries the reason words only. Put the retry countdown in glcd DIM at the panel's top right in both states. Re-render both.

## Should-fix

1. **"Page open" must mean the page, not the probe.** Every path returns the page, so iOS's `/hotspot-detect.html` probe flips the state to `Page open` even when no sheet appears. That's exactly the case `joined-nopage` exists for. Have the page's JS send a one-line `fetch('/hi')` on load, and flip the state on that.
2. **Hold on resistive touch.**
   - Bit-banged pressure drops out for a few samples, so a steady thumb will reset the hold. Tolerate gaps under 150 ms.
   - Start the fill on touch-down, so a tap visibly *begins* something.
   - On a release under 1 s, flash `Keep holding` for 1 s.
   - This is what makes the hold discoverable: the label alone is fine, but silence after a tap isn't.
3. **The countdown lies once a phone is joined.** `closes in 13 min` shows in the joined and page states, but those states are governed by the 30-min since-last-request rule. Hide it once a station is associated.
4. **Two-gate wording for a non-technical owner.**
   - `0.4 mi from Gilbert, AZ. Too far for the street map` reads like a bug: 0.4 mi isn't "far" to anyone. Say `0.4 mi from the map center. Streets only line up within 0.1 mi, so the map shows planes without streets. Radar and weather work.` Use "map center" in all three states.
   - For the far state, split the long sentence in two: `Works here: weather, plane cards, the plane map without streets.` / `Off here: rain radar (built for Gilbert, AZ).`
5. **The cleared Name still shows `Gilbert, AZ`.** The placeholder is `S.buildPlace`, so after the #far state clears it, the field *looks* unchanged. Set the placeholder to `e.g. Home` when outside the radar gate.
6. **`tzGuess` misplaces western Arizona.** Yuma (-114.62) hits `lon<-114.5 → pt` before the Arizona box. Test the Arizona box first. Also give no hint outside the rough US bounds: London would currently get `Looks like Eastern.`
7. **The two location parsers disagree.**
   - The page accepts `33.35280 N lat, 111.78900 W`, because it blanks out unknown letters. The firmware rejects it, so the page says `Reads as…` and then Save fails.
   - The firmware accepts longitude-first DMS, and the page doesn't.
   - *Fix:* port the tokenizer to JS line for line, and keep one shared table of test strings in the repo.
8. **Scan again throws away edits** and blocks the sync server for about 3 s while the AP hops channel. Show `Scanning, about 5 s…`, and keep the location/facing/tz edits across the reload with `sessionStorage` (it survives the reload even if it's lost later).
9. **Settings `Done` is 30 px** (`portal_screen.py:122`); R2-9 says ≥ 36.
