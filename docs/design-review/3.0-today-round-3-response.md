All three port-time should-fixes are done in the firmware.

1. **Chip → map with the plane gone.**
   - `mapOpenPassed(hex, label, until)` (ui_map.cpp): if the hex isn't in the first snapshot, the
     strip reads `<label>  out of range` (TEXT / MUTED, no chevron) for 4 s, then the map is
     normal.
   - It's drawn as its own strip branch, not a `mapStripRight()` kind: the left side is the passed
     plane's words, not the focus plane's, so the width tests for focus strips don't apply.
2. **The chip-passed tier in `mapPickFocus()`** is a new argument below just-popped, and it's
   host-tested (test_map.cpp):
   - it beats nearest
   - just-popped beats it
   - a selection beats it
   - a will-pop plane beats it
   - it's dropped when the plane leaves the traffic

   The 10-min end is the chip's window (`chipMessage` expiry test), passed in as `untilMs`.
